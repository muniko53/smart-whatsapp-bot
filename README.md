# Smart WhatsApp Assistant

Standalone WhatsApp customer support bot and management dashboard.

## Why This Exists

Provides automated WhatsApp messaging and customer interaction management for small businesses and platforms, featuring a layered backend and a clean web dashboard.

## Status

**Prototype** — in active evaluation.

*Last updated: September 2026*

## Features

- WhatsApp message handling and response automation
- Layered backend architecture
- Web dashboard for monitoring and configuration
- Admin authentication and session management
- Security hardening (rate limits, input validation, brute-force guards)

## Tech Stack

- Python
- Flask / FastAPI backend
- JavaScript frontend
- Docker / Render / Vercel configurations

## Setup

### Prerequisites

- Python 3.10+
- Node.js (for frontend)

### Install & Run

```powershell
git clone https://github.com/muniko53/smart-whatsapp-bot.git
cd smart-whatsapp-bot
# See start.bat or requirements.txt for service startup
```
