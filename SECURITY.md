# Security Policy

## Reporting a Vulnerability

If you discover a security issue in this repository, please report it privately.

**Email:** jacobmuniko53@gmail.com

**Do NOT:**
- Open a public GitHub issue for security vulnerabilities
- Include sensitive data (tokens, keys, credentials) in your report

**Include in your report:**
- Description of the issue
- Steps to reproduce
- Impact assessment
- Suggested fix (if any)

## Supported Versions

Only the latest release receives security updates.

## Scope

This repository handles WhatsApp bot integration and dashboard credentials. These are stored as environment variables and never committed to version control.
